## The stack (`stack/r24/`)

1. **01-game-icons** — a square icon slot per game, fetched from the stores; the strip and every small mark show the icon beside the name (never the wordmark); the logo keeps the big spots (hub header, games list, Dailies card). Every icon size up: strip 44/48 px, list marks 32, tiles 36/56, hub 120, list 72.
2. **02-key-art** — the key-art slots' sources: each wiki's current version splash; the hub header and the games list show it big.
3. **03-preview-icons** — the timeline's selected panel, the Banners & events bars, Home's lists (expiring, next resets) and the version card: game icon, kind mark, key-art thumbnail, no bare text.
4. **04-history** — Game8 banner history as an importer (pinned snapshot) for Wuthering Waves, Endfield, NTE; Zenless from its wiki's channel pages; the Pulls history for every game.
5. **05-endfield-art** — hi-res Endfield art from the official wiki or endfield.gg; the missing Endfield icons.
6. **06-tasks** — fuller default tasks per game from the sites, with counts; existing profiles get the new defaults.
7. **07-cards** — event cards for the non-HoYo games (Game8 events) and battle-pass cards with their version art.
8. **08-docs** — ASSETS.md, the handoff.

## Decisions

- Icons at small sizes, logos at big sizes: a wordmark at 30 px reads as nothing (Georges); the app icon is what he recognises.
- Sources are fetched into the store once (Settings → Art, one click), never hotlinked from stores or wikis.
- PR screenshots keep blocking game art (the repository is public, ADR 0006); the real-art shots go to Georges directly in the session.
